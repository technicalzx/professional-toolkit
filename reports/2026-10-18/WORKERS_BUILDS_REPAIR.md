## Research and adopted decisions

| Primary source | Problem / architecture pattern | Decision and maintenance concern |
| --- | --- | --- |
| [Cloudflare Workers SDK](https://github.com/cloudflare/workers-sdk) / [Preview prerequisites](https://developers.cloudflare.com/workers/previews/get-started/) | Old project CLI cannot target the new Preview deployment contract. | Adapt the existing development dependency to pinned Wrangler 4.135.0, the documented minimum. Installed package license `MIT OR Apache-2.0`; no upstream source copied. Satisfies the seven-day release-age policy. CLI internally uses Miniflare 5 alpha; preserve lockfile, audit and runtime checks. |
| [Preview configuration](https://developers.cloudflare.com/workers/previews/configuration/) and [resource isolation](https://developers.cloudflare.com/workers/previews/resources/) | A Preview URL alone does not isolate account data or inherit all required bindings. | Explicit Preview D1/AI/model/operational logs; assets and compatibility remain top-level. Separate database from production, initialized once with existing 11-statement schema. Previews choosing the same UUID share data. No customer records copied and no AI invoked. |
| [Builds API](https://developers.cloudflare.com/workers/ci-cd/builds/api-reference/) / connected OpenAPI `patch_existing_previews` parameter | Saved Base values did not prove the existing trigger's effective settings. | Read the failed build's actual target and inspect it directly. Patch Base with `patch_existing_previews=false` and selected existing Preview independently; read back both. Preserve production settings, other branches, connection, build token and unrelated variables. |

Repairing the broken review pipeline ranked above new features: it unlocks repeatable backend and extension acceptance, has a bounded compatibility scope and fits the existing Worker/D1 architecture. Defer extra providers, broad permissions, new frameworks and automatic production promotion.
